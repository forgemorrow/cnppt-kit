# Security Policy

## Scope

`cnppt-kit` compiles local Markdown and JSON presentation specifications into native `.pptx` and self-contained HTML5 files strictly offline without invoking external fonts, scripts, or dynamic code execution (`eval`).

## Supported Versions

| Version | Supported |
| --- | --- |
| `0.1.x` | Yes |

## Reporting a Vulnerability

If you discover a malformed XML/OOXML handling bug, path-traversal issue, or security concern in `cnppt-kit`, please report it privately via GitHub Security Advisories on this repository.
